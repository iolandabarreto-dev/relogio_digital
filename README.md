# 🚀 Relógio Digital

## 📌 Sobre o projeto
Este projeto é uma aplicação web simples que exibe um relógio digital em tempo real, atualizando automaticamente horas, minutos e segundos.  


________________________________________
🎯 Objetivo  
Criar um relógio digital funcional e estilizado que atualiza em tempo real no navegador.  

________________________________________
✨ Funcionalidades  
- Exibição de horas, minutos e segundos em tempo real  
- Atualização automática a cada segundo  
- Interface minimalista e responsiva  
- Estilo moderno com destaque visual em tela escura  

________________________________________
🛠️ Tecnologias utilizadas  
- **HTML5** para estruturação da página  
- **CSS3** para estilização e layout responsivo  
- **JavaScript (ES6)** para lógica de atualização do relógio  

________________________________________
📂 Estrutura do projeto  
```
├── index.html        # Página principal
├── styles.css        # Estilos da aplicação
├── scripts.js        # Lógica do relógio digital
└── README.md         # Documentação do projeto
```
